# T-231: Activity bar component (left)

## Objective
Build the activity bar component with tool icons and panel toggles.

## Acceptance Criteria
- [ ] `ActivityBar` widget in `activity_bar.rs`
- [ ] Width: 48 px collapsed, expands to 200 px on hover (animated 150 ms)
- [ ] Top section: tool buttons (Select, Wall, Door, Window, Dimension, Measurements, Block, Construction, Label)
- [ ] Middle section: panel toggles (Inspector, Layers, Constraints, Blocks, Output)
- [ ] Bottom section: Settings, About, Release Notes, Check for Updates
- [ ] Active tool highlighted: `SPEC.component.activity_bar.active_background`
- [ ] Active panel toggle highlighted: same token
- [ ] Tooltips show name + shortcut (e.g., "Inspector (I)")
- [ ] Icons from `theme::icon_texture()` (SVG rasterized)
- [ ] Keyboard: `Tab`/`Shift+Tab` navigates, `Enter`/`Space` activates

## Target Files
- `apps/lintel/src/activity_bar.rs` (new)
- `apps/lintel/src/app.rs` (integration)

## Out of Scope
- Panel content (handled by docking)
- Theme switch dropdown (T-226)

## Dependencies
- T-222 (dock rendering — activity bar toggles panel visibility)

## Estimated Size
Medium — widget + icons + hover expansion + keyboard
