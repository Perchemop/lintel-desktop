# T-224: Dark and High-Contrast palettes in theme.rs

## Objective
Add `dark_palette()` and `high_contrast_palette()` to `theme.rs` with full token coverage.

## Acceptance Criteria
- [ ] `dark_palette() -> ThemeSpec` returns complete three-tier tokens (BASE → semantic → component)
- [ ] `high_contrast_palette() -> ThemeSpec` returns complete three-tier tokens
- [ ] Both palettes use same semantic role names as `light_palette()`
- [ ] Dark: WCAG AA floors (4.5:1 body, 3:1 UI boundaries, 7:1 HC text)
- [ ] High-Contrast: WCAG AAA floors (7:1 body, 4.5:1 UI, 7:1 HC text)
- [ ] `contrast_test()` extended to assert all three palettes
- [ ] CI `contrast-test` job passes for all three

## Target Files
- `apps/lintel/src/theme.rs` (palette fns + contrast_test extension)

## Out of Scope
- Runtime theme switching (T-225)
- Theme persistence (T-226)

## Dependencies
- None (pure theme.rs work)

## Estimated Size
Medium — two new palettes + contrast test extension
