# T-223: Layout persistence (save/restore DockState)

## Objective
Persist `DockState` to `AppSettings` on change and restore on startup.

## Acceptance Criteria
- [ ] `AppSettings.dock_state: Option<String>` (JSON serialized `DockState`)
- [ ] Serialize on: panel close, panel move, tab reorder, window close
- [ ] Deserialize on startup; fallback to default layout on failure
- [ ] Settings → "Reset Layout" button clears `dock_state` and restores default
- [ ] Unit test: serialize → deserialize → layout matches

## Target Files
- `apps/lintel/src/settings.rs` (dock_state field)
- `apps/lintel/src/app.rs` (save on change, load on init)
- `apps/lintel/src/settings_ui.rs` (reset button)

## Out of Scope
- Version migration for dock state (future)

## Dependencies
- T-222 (dock rendering)

## Estimated Size
Small — serialization + settings integration
