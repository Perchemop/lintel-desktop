# T-235: Extend contrast_test for Dark + High-Contrast palettes

## Objective
Update `theme::contrast_test()` to assert all three palettes meet their contrast floors.

## Acceptance Criteria
- [ ] `contrast_test()` walks all text/UI pairings for Light, Dark, High-Contrast
- [ ] Floors per palette:
  - Light: 4.5:1 body, 3:1 UI boundaries, 7:1 HC text
  - Dark: 4.5:1 body, 3:1 UI boundaries, 7:1 HC text
  - High-Contrast: 7:1 body, 4.5:1 UI boundaries, 7:1 HC text
- [ ] Failure message includes: palette, role, measured ratio, required ratio
- [ ] CI `contrast-test` job runs all three and passes
- [ ] No false positives from disabled pairings (held to 4.5:1)

## Target Files
- `apps/lintel/src/theme.rs` (contrast_test extension)

## Out of Scope
- Palette definitions (T-224)

## Dependencies
- T-224 (palettes exist)

## Estimated Size
Small — test extension
