# T-237: egui_kittest AccessKit assertions for workbench shell

## Objective
Add AccessKit assertions for activity bar, status bar, editor tabs, and theme dropdown.

## Acceptance Criteria
- [ ] Activity bar: tool buttons have `Role::Button`, labelled, 24 pt minimum
- [ ] Panel toggles: `Role::ToggleButton` or `Role::Button`, labelled with panel name
- [ ] Status bar: coords/chips/zoom announced as `Role::StaticText` or `Role::Label`
- [ ] Theme dropdown: `Role::ComboBox`, options announced, current selected
- [ ] Editor tabs: `Role::TabList` + `Role::Tab`, selected announced
- [ ] Tab close buttons: `Role::Button`, labelled "Close Sheet N"
- [ ] Focus order: Tab traverses activity bar → editor tabs → canvas → status bar → dock panels
- [ ] No focus traps; Escape dismisses dropdowns
- [ ] Tests in `kittest_shell.rs` (new), run in `check` CI job

## Target Files
- `apps/lintel/src/tests/kittest_shell.rs` (new)

## Out of Scope
- Rendered evidence (T-236)

## Dependencies
- T-234 (shell integrated)

## Estimated Size
Medium — multiple AccessKit assertions
