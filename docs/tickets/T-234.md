# T-234: Workbench shell integration in App::update()

## Objective

## Acceptance Criteria

  2. Horizontal: ActivityBar (left, 48/200 px) | DockArea (centre, flex)

- [ ] DockArea fills centre, shows Canvas in centre + docked panels
- [ ] Activity bar toggles panel visibility in DockState
- [ ] Editor tabs control active sheet view
- [ ] Status bar shows all sections
- [ ] No layout overflow; all components use tokens
- [ ] Responsive at 800×600 minimum
