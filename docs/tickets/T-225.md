# T-225: ThemeMode enum, AppSettings persistence, runtime switch

## Objective
Add `ThemeMode` enum, persist in `AppSettings`, implement runtime theme switching.

## Acceptance Criteria
- [ ] `ThemeMode` enum: `Light | Dark | HighContrast | System`
- [ ] `AppSettings.theme_mode: ThemeMode` (default `System`)
- [ ] `AppState.set_theme_mode(mode)` updates `eframe::Frame::set_visuals()`
- [ ] Startup: reads `theme_mode`, applies (System → follows OS via `Visuals::dark_mode`)
- [ ] Runtime switch: immediate visual update, persists to settings
- [ ] No restart required

## Target Files
- `apps/lintel/src/theme.rs` (ThemeMode enum)
- `apps/lintel/src/settings.rs` (theme_mode field)
- `apps/lintel/src/app.rs` (set_theme_mode + startup apply)

## Out of Scope
- UI for theme switching (T-226)
- Shortcut (T-227)

## Dependencies
- T-224 (palettes exist)

## Estimated Size
Small — enum + persistence + runtime apply
