# T-227: Ctrl+T theme cycle shortcut

## Objective
Add `Ctrl+T` shortcut to cycle through theme modes.

## Acceptance Criteria
- [ ] `Ctrl+T` cycles: Light → Dark → HighContrast → System → Light
- [ ] Shortcut works globally (not just when status bar focused)
- [ ] Shortcut hint shown in status bar dropdown tooltip
- [ ] Respects reduced-motion (no animation on cycle)

## Target Files
- `apps/lintel/src/app.rs` (shortcut handling)
- `apps/lintel/src/status_bar.rs` (tooltip update)

## Out of Scope
- ThemeMode enum/persistence (T-225)
- Dropdown UI (T-226)

## Dependencies
- T-225 (ThemeMode + runtime switch)

## Estimated Size
Tiny — single shortcut handler
