# T-228: CanvasHints struct and hover detection

## Objective
Add `CanvasHints` struct to track hover state and detect what entity is under cursor.

## Acceptance Criteria
- [ ] `CanvasHints` struct in `canvas.rs` with fields:
  - `hovered_entity: Option<HoveredEntity>` (enum: Wall, Opening, Dimension, AnchorGrip, None)
  - `hints_enabled: bool` (default true)
  - `fade_state: FadeState` (In/Out/Visible/Hidden with timer)
- [ ] `Canvas::hovered_entity_at(pos: Pos2) -> Option<HoveredEntity>` uses existing hit-test
- [ ] `CanvasHints::update(dt, hovered)` called each frame
- [ ] Fade animation: 150 ms in, 300 ms out, respects reduced-motion
- [ ] `H` key toggles `hints_enabled`

## Target Files
- `apps/lintel/src/canvas.rs` (CanvasHints + hover detection + H key)

## Out of Scope
- Hint rendering (T-229)
- Status bar contextual hints (T-230)

## Dependencies
- None (pure canvas.rs work)

## Estimated Size
Small — struct + detection + animation logic
