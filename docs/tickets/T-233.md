# T-233: Editor tabs component (top)

## Objective
Build the editor tabs bar above the canvas for Plan + Sheet tabs.

## Acceptance Criteria
- [ ] `EditorTabs` widget in `editor_tabs.rs` (new)
- [ ] Plan tab: always first, pinned, non-closeable, icon = document
- [ ] Sheet tabs: one per sheet in drawing set, closeable (×), icon = layout
- [ ] "+" button after last sheet tab: adds new sheet viewport
- [ ] Active tab: `SPEC.component.tab.active_background`
- [ ] Hover: `SPEC.component.tab.hover_background`
- [ ] Close button: `SPEC.component.tab.close_button`
- [ ] Drag to reorder sheet tabs (Plan stays first)
- [ ] Click tab → switches active view (Plan ↔ Sheet N)
- [ ] Keyboard: `Ctrl+Tab` / `Ctrl+Shift+Tab` cycles, `Ctrl+W` closes sheet tab

## Target Files
- `apps/lintel/src/editor_tabs.rs` (new)
- `apps/lintel/src/app.rs` (integration + sheet management)

## Out of Scope
- Sheet viewport rendering (existing)
- Drawing set management (existing)

## Dependencies
- None (pure widget + integration)

## Estimated Size
Small — widget + integration
