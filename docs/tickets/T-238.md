# T-238: Layers panel content (visibility, lock, colour, add/remove)

## Objective
Implement full Layers panel content in the docked panel.

## Acceptance Criteria
- [ ] Layer list: each row shows visibility (eye), lock (lock), colour swatch, name
- [ ] Visibility toggle: hides layer entities on canvas
- [ ] Lock toggle: prevents selection/editing of layer entities
- [ ] Colour swatch: click → colour picker (uses `SPEC.component.color_picker`)
- [ ] Name: editable on double-click (uses `SPEC.component.field`)
- [ ] "Add Layer" button at bottom: creates new layer with default colour
- [ ] "Remove Layer" button per row (disabled for default layer)
- [ ] Drag to reorder layers (changes draw order)
- [ ] Keyboard accessible: Tab navigates, Space toggles, Enter edits name

## Target Files
- `apps/lintel/src/layers.rs` (full implementation)
- `apps/lintel/src/layer.rs` (core — ensure Layer has colour, visible, locked)

## Out of Scope
- Dock integration (T-222)
- Canvas layer filtering (existing)

## Dependencies
- T-222 (panel rendered in dock)

## Estimated Size
Medium — list + interactions + colour picker
