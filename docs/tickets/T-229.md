# T-229: Render on-canvas hover hints

## Objective
Render hover hints near cursor using `SPEC.component.hint.*` tokens.

## Acceptance Criteria
- [ ] Hint rendered in `Canvas::paint()` after entities, before selection overlay
- [ ] Position: cursor + 12 px offset, clamped to canvas bounds
- [ ] Background: `SURFACE_SUNKEN`, Text: `TEXT_MUTED`, Border: `BORDER_SUBTLE`
- [ ] Rounded corners: `SPEC.component.hint.radius` (4 px)
- [ ] Padding: `SPEC.component.hint.padding` (8 px horizontal, 4 px vertical)
- [ ] Max width: 280 px, wraps text
- [ ] Fade animation driven by `CanvasHints.fade_state`
- [ ] Hidden when `hints_enabled = false`

## Hint Text per Entity
| Entity | Text |
|--------|------|
| Wall | "Wall N: {length} mm, {thickness} mm thick" |
| Opening | "{Door/Window} D1: {width}×{height} mm, {left/right}-hand" |
| Dimension | "Dim 5: {value} mm, offset {offset} mm" |
| AnchorGrip | "Drag to move anchor along wall (param {p:.0%})" |

## Target Files
- `apps/lintel/src/canvas.rs` (hint rendering in paint)

## Out of Scope
- CanvasHints struct (T-228)
- Status bar contextual hints (T-230)

## Dependencies
- T-228 (CanvasHints + hover detection)
