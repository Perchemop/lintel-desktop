# T-230: Contextual status bar hints per active tool

## Objective
Show contextual hints in status bar left section based on active tool and selection state.

## Acceptance Criteria
- [ ] Status bar left section shows tool-specific hint
- [ ] Hints use `SPEC.component.status_bar.hint_text` token
- [ ] Updated each frame based on `AppState.active_tool` and selection

## Hint Text per Tool/State
| Tool / State | Hint |
|--------------|------|
| Select, nothing selected | "Click wall to select • Shift+Click multi-select • Esc clear" |
| Select, wall selected | "Drag to move • Click dimension to edit • Del delete • Esc clear" |
| Select, dimension selected | "Drag to change offset • Click grip to anchor • Del delete • Esc clear" |
| Wall | "Click to start • Move to preview • Click to place • Esc cancel" |
| Door | "Click wall to place door • Esc cancel" |
| Window | "Click wall to place window • Esc cancel" |
| Dimension | "Click first point • Click second point • Esc cancel" |
| Measurements | "Click room to measure • Esc cancel" |
| Block | "Click to place instance • Esc cancel" |
| Construction (Line/Ray/Circle/Arc) | "Click first point • Click second point • Esc cancel" |
| Label | "Click to place label • Type text • Enter confirm • Esc cancel" |

## Target Files
- `apps/lintel/src/status_bar.rs` (hint text logic)
- `apps/lintel/src/app.rs` (pass tool/selection to status bar)

## Out of Scope
- Canvas hover hints (T-228/T-229)

## Dependencies
- None (pure status_bar.rs work)

## Estimated Size
Small — match statement + text
