# T-221: Panel enum and default dock layout

## Objective
Define the panel enum and create the default dock layout with all five panels.

## Acceptance Criteria
- [ ] `Panel` enum in `panels.rs`: `Inspector`, `Layers`, `Constraints`, `Output`, `Canvas`
- [ ] `impl Panel { fn title(&self) -> &'static str; fn id(&self) -> &'static str; }`
- [ ] Default `DockState` constructor creates tree:
  - Root: horizontal split [Left: Inspector+Layers+Constraints tabs, Centre: Canvas, Right: (empty), Bottom: Output]
  - Inspector, Layers, Constraints tabbed together on right
  - Output at bottom
  - Canvas in centre (non-dockable marker)
- [ ] Unit test: default layout has all 5 panels

## Target Files
- `apps/lintel/src/panels.rs` (new)
- `apps/lintel/src/app.rs` (default layout init)

## Out of Scope
- Panel content rendering
- User layout modifications

## Dependencies
- T-220 (egui_dock + DockState in AppState)

## Estimated Size
Small — enum + constructor + test
