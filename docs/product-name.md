# Product Name

**Lintel**

The name "Lintel" was chosen because:

1. **Structural role:** A lintel is a architectural element spanning openings (doors, windows) in walls — exactly the core concept of this app: walls with openings.

2. **Clarity over cleverness:** The name immediately communicates the app's purpose (working with lintel/opening structures) without being obscure or culture-specific.

3. **Handle availability:** The name "lintel" has not been registered as a trademark in the relevant categories for software tools, and the GitHub handle `@perchemop/lintel-desktop` was available (the repository URL referenced in `lintel-core`'s `Cargo.toml`).

4. **No false affiliation:** The name does not imply any association with commercial CAD products or hardware manufacturers.

5. **Pronunciation:** /ˈlɪntəl/ (LIN-tel) — easy to say and spell in most languages.

The product name "Lintel" is recorded in `docs/product-name.md` and will be used as the window title, binary name, and GitHub repository name going forward.
