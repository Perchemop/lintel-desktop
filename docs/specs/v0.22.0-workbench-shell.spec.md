# v0.22.0 — Workbench Shell, Runtime Themes & Docking

## Summary

This feature release transforms Lintel from a single-window app into a professional **workbench** with:

1. **Workbench shell** — activity bar, status bar, editor tabs, and panel system
2. **Runtime theme switch** — user-selectable Light / Dark / High-Contrast palettes persisted in settings
3. **Docking framework** — draggable, tabbed panels via `egui_dock` (Inspector, Canvas, Output, Layers, Constraints)
4. **On-canvas hints** — contextual tooltips and status hints on hover/selection

All built on the v0.20.0 design system (three-tier tokens, contrast methodology, rendered evidence) and v0.21.0 test hardening.

## 1. Workbench Shell

### 1.1 Activity Bar (Left)

| Area | Content |
|------|---------|
| Top | Tool icons: Select (S), Wall (W), Door (D), Window (N), Dimension (M), Measurements (Shift+M), Block (B), Construction (C/Q/X), Label (L) |
| Middle | Panel toggles: Inspector (I), Layers (Y), Constraints (K), Blocks (B), Output (O) |
| Bottom | Settings (gear), About, Release Notes, Check for Updates |

**Behaviour:**
- Single-click toggles panel visibility
- Active panel highlighted with `SPEC.component.activity_bar.active_background`
- Tooltips show shortcut (e.g., "Inspector (I)")
- Width: 48 px (compact) / 200 px (expanded on hover)

### 1.2 Status Bar (Bottom)

| Section | Content |
|---------|---------|
| Left | Cursor coordinates (format per `UnitSystem`), snap/ortho/grid chips |
| Centre | Selection count, active level name, zoom % |
| Right | Theme selector (Light / Dark / High-Contrast), Git status (if repo), Update badge |

**Behaviour:**
- Height: 28 px (`SPEC.component.status_bar.height`)
- Chips use `SPEC.component.chip.*` tokens
- Theme selector opens a dropdown with radio items

### 1.3 Editor Tabs (Top, above Canvas)

| Tab | Content |
|-----|---------|
| Plan | Main drawing canvas (always present, cannot close) |
| Sheet N | Viewport sheet tabs (one per sheet in drawing set) |
| + | New sheet button |

**Behaviour:**
- Plan tab always first, pinned
- Sheet tabs closeable (removes viewport from drawing set)
- Active tab: `SPEC.component.tab.active_background`
- Hover: `SPEC.component.tab.hover_background`
- Drag to reorder sheet tabs

## 2. Runtime Theme Switch

### 2.1 Palettes

| Palette | Source | Tokens |
|---------|--------|--------|
| Light | `theme::light_palette()` (existing) | All `BASE_*` swatches + semantic roles |
| Dark | `theme::dark_palette()` (new) | New swatches, same semantic roles, WCAG AA |
| High-Contrast | `theme::high_contrast_palette()` (new) | New swatches, WCAG AAA (7:1 text, 4.5:1 UI) |

### 2.2 Implementation

- Add `ThemeMode` enum: `Light | Dark | HighContrast | System`
- `AppSettings.theme_mode: ThemeMode` persisted in `settings.json`
- On startup: apply `ThemeMode::System` → follow OS preference (egui's `Visuals::dark_mode`)
- Runtime switch: `AppState.set_theme_mode()` → updates `eframe::Frame::set_visuals()` + persists
- `contrast_test` CI job extended to assert all three palettes

### 2.3 UI Entry Points

- Status bar dropdown (primary)
- Settings panel (secondary)
- Shortcut: `Ctrl+T` cycles Light → Dark → High-Contrast → System

## 3. Docking Framework (`egui_dock`)

### 3.1 Panels (Dockable)

| Panel | Default Location | Content |
|-------|------------------|---------|
| Inspector | Right | Project, Storeys, Constraints, Viewports, Blocks, Block Instance, Measurements |
| Layers | Right (tabbed with Inspector) | Layer list: visibility, lock, colour, add/remove |
| Constraints | Right (tabbed) | Level constraint list + add form |
| Output | Bottom | Command log, solver status, warnings, measurements output |
| Canvas | Centre | Plan drawing (non-dockable, always visible) |

### 3.2 Layout Persistence

- `AppSettings.dock_state: Option<String>` (serialized `egui_dock::DockState`)
- Saved on panel close/move, restored on startup
- Reset to default via Settings → "Reset Layout"

### 3.3 Tab Behaviour

- Panel tabs: `SPEC.component.dock.tab.*` tokens
- Close button on each tab (hides panel, not destroy)
- Double-click tab header → maximize panel (toggle)
- Drag tab → detach as floating window (future) / reorder

## 4. On-Canvas Hints

### 4.1 Hint Types

| Trigger | Hint | Position |
|---------|------|----------|
| Hover wall | "Wall N: 3000 mm, 200 mm thick" | Near cursor, offset 12 px |
| Hover opening | "Door D1: 900×2100, left-hand" | Near cursor |
| Hover dimension | "Dim 5: 4500 mm, offset 200 mm" | Near cursor |
| Hover anchor grip | "Drag to move anchor along wall" | Near grip |
| Select tool, nothing selected | "Click wall to select • Shift+Click multi-select • Esc clear" | Status bar left |
| Wall tool, no wall under cursor | "Click to start wall • Shift+Click for ortho" | Status bar left |
| Dimension tool, placing | "Click first point • Click second point • Esc cancel" | Status bar left |

### 4.2 Implementation

- `CanvasHints` struct in `canvas.rs` tracks hover state
- Rendered in `Canvas::paint()` after entities, before selection overlay
- Uses `SPEC.component.hint.*` tokens (background `SURFACE_SUNKEN`, text `TEXT_MUTED`, border `BORDER_SUBTLE`)
- Fade-in 150 ms, fade-out 300 ms (respects reduced-motion)
- Keyboard: `H` toggles hints on/off

## 5. Acceptance Criteria

### 5.1 Workbench Shell

- [ ] Activity bar renders left, 48 px, expands on hover
- [ ] Activity bar icons toggle corresponding panels
- [ ] Status bar renders bottom, 28 px, shows coords/chips/zoom/theme
- [ ] Editor tabs render top: Plan (pinned) + Sheet tabs (closeable)
- [ ] All shell elements use `SPEC.component.*` tokens — no raw `Color32`

### 5.2 Runtime Theme Switch

- [ ] Light / Dark / High-Contrast palettes defined in `theme.rs`
- [ ] `ThemeMode` enum + `AppSettings.theme_mode` persisted
- [ ] Startup applies saved mode (System follows OS)
- [ ] Status bar dropdown switches theme at runtime
- [ ] `Ctrl+T` cycles themes
- [ ] `contrast_test` asserts all three palettes meet floors
- [ ] No visual regressions in rendered evidence (CI)

### 5.3 Docking Framework

- [ ] `egui_dock` integrated, DockState in `AppState`
- [ ] Five panels dockable: Inspector, Layers, Constraints, Output, (Canvas centre)
- [ ] Panels tabbed, closeable, reorderable
- [ ] Layout persisted in `settings.json`, restored on startup
- [ ] Settings → "Reset Layout" restores default

### 5.4 On-Canvas Hints

- [ ] Hover hints for walls, openings, dimensions, anchors
- [ ] Contextual status-bar hints per active tool
- [ ] `H` toggles hints
- [ ] Hints use `SPEC.component.hint.*` tokens
- [ ] Fade animation respects reduced-motion

## 8. Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| `egui_dock` API mismatch with egui 0.36 | Pin compatible version; test in CI before merge |
| Theme switch flicker on large projects | Debounce visual update; test with 1000+ entities |
| Dock state serialization breaks on version upgrade | Version the dock state; graceful fallback to default |
| Performance regression from hints | Profile hint rendering; cache hover state; disable in benchmarks |
