# v0.20.0 Specification — Design System Extensions (Copy Patterns)

**Status:** Approved for implementation (human gate passed 2026-11-19)
**Source research:**
- `docs/research/design-audit-egui-ecosystem.md` (egui-pop, shadcn-egui, spaceui, modern-egui)
- `docs/research/design-audit-drafting-uis.md` (LibreCAD/QCAD/FreeCAD behavioural patterns)
**Guide references:** II.30 (stack matching, tokens first, A11y as code, evidence), II.27 (designer role), §19 rule 3 (measured only)

---

## Scope

Extend Lintel's existing token/module (`apps/lintel/src/theme.rs`) with copy-pattern implementations from the approved research. All selected crates target egui 0.37+ and are **incompatible with Lintel's pinned egui 0.36.2** — no crate adoption, only pattern reimplementation.

### In Scope (copy patterns only)

| Pattern | Source | Lintel Target |
|---------|--------|---------------|
| **Button system** — 4 roles × 3 sizes with `StyledButton` widget | `shadcn-egui`, `modern-egui`, `egui-pop` | `theme.rs` component tokens + `components/buttons.rs` |
| **Field/Form composition** — `Field`, `FieldSet`, `FieldGroup` with label/error/help slots | `shadcn-egui` | `components/forms.rs` |
| **Flexbox layout helpers** — `vstack`, `hstack`, `wrap_row`, `card` solving egui single-pass layout | `shadcn-egui` | `layout/helpers.rs` |
| **SVG icon rasterization** — exact-pixel-size SVG → texture, no Lucide dependency | `spaceui` | `assets/icons/*.svg` + `theme::icon_texture()` |
| **Shell Regions pattern** — `Shell { title_bar, rail, columns }` returned as `Regions` to fill | `spaceui` | `app/shell.rs` restructure |
| **ThemeSpec three-tier tokens** — Reference palette → System roles → Component tokens (DTCG) | `egui-pop` | Extend `theme.rs` tier structure |
| **WCAG AA contrast methodology** — 4.5:1 body, 3:1 UI parts, 7:1 high-contrast, CI gate | `egui-pop` | Extend existing `theme::contrast_test()` |

### Out of Scope

- Any crate adoption (egui version mismatch)
- Full design system framework (egui-pop host contract, agent system)
- Web design systems (Astryx, shadcn/ui, Tailwind, StyleX — per II.30.1 non-goal)
- Docking framework (egui_dock/egui_stack) — separate milestone
- Workbench shell (activity bar, status bar, editor tabs) — separate milestone

## Acceptance Criteria

| ID | Criterion | Verification |
|----|-----------|--------------|
| AC-01 | Button component tokens defined in `theme.rs` (primary/secondary/ghost/danger × sm/md/lg) | Grep: `BUTTON_*` roles exist; no raw `Color32` in button code |
| AC-02 | `StyledButton` widget renders all 12 variants with 24pt minimum target size | `egui_kittest` AccessKit assertions: role=button, name present, size ≥ 24pt |
| AC-03 | `Field`/`FieldSet`/`FieldGroup` components accept label, error, help text | Unit tests in `components/forms.rs`; rendered evidence in PR |
| AC-04 | `vstack`/`hstack`/`wrap_row`/`card` layout helpers work without overlapping | Integration test: resize window → no clipping/overlap (II.30.7.6) |
| AC-05 | SVG icons load as textures at exact size; no Lucide crate in `Cargo.toml` | `grep -r Lucide Cargo.toml` empty; icon renders crisp at 16/20/24pt |
| AC-06 | Shell restructured as `Shell::regions(&ctx) -> Regions { title_bar, rail, canvas }` | `main.rs` uses `Shell::regions()`; three zones visually distinct |
| AC-07 | Token tiers: BASE_* (raw) → SEMANTIC_* (roles) → COMPONENT_* (widget) all in `theme.rs` | `grep -n "BASE_\|SEMANTIC_\|COMPONENT_" theme.rs` shows three tiers |
| AC-08 | Contrast test asserts light, dark, high-contrast palettes (4.5:1/3:1/7:1) | `cargo test contrast_test` passes in CI; CI gate in `.ci-required.txt` |
| AC-09 | Rendered evidence: light/dark theme, empty/error/loading states, narrow window | Screenshots attached to PR; `egui_kittest` assertions for keyboard/focus |
| AC-10 | ROADMAP/CHANGELOG/PROGRESS updated; `docs/tokens.md` ledger row appended | Files modified; CI green; version bumped to 0.20.0 |

## Non-Goals / Constraints

- **No egui version bump** — stays 0.36.2 (separate slice if needed)
- **No new design-system crates** — one design path rule (II.30.1)
- **No raw `Color32` outside `theme.rs`** — CI grep gate enforced
- **All tests headless** — no display required (K.13)
- **CI verification only** — no local `cargo` (HARD BUILD RULE)
